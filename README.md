# AI Search Visibility Journal

A manual checklist and CSV template for recording how AI tools describe a brand or product.

This repository contains documentation and a blank observation template. It is **not an automated checker**, and it does not include the Jianwei GEO SaaS source code.

## Why keep a journal?

A screenshot can omit the prompt, search mode, date, or cited sources. A structured record makes observations easier to revisit without presenting one favorable answer as a reliable ranking.

## How to use

1. Download `observations.csv` and open it in a spreadsheet.
2. Prepare separate groups of prompts: brand facts, recommendations without the brand name, and comparisons with real alternatives.
3. Start a new conversation for each observation and preserve the exact prompt and full answer.
4. Record the platform, access method, visible model/mode, search setting, timestamp, and cited URLs. Use `unknown` when a field is unavailable.
5. Mark mentions, recommendations, official-site citations, and factual errors separately. Human review is needed for recommendation context.
6. Repeat under comparable conditions and keep all observations, including unfavorable ones.

The CSV intentionally has no sample results. An unperformed test must not be recorded as a negative result.

## Interpretation limits

- Official API output is not equivalent to output in a consumer chat app.
- A brand mention is not necessarily a recommendation.
- A reachable webpage is not proof of indexing or AI citation.
- Before/after differences alone do not establish causation.
- Visits, inquiries, and sales are separate outcomes.
- Do not include customer data, credentials, or other private information in a public record.
